# Algorithm: AVL Tree LL Rotation

1. Start the program and initialize an empty AVL tree.

2. Insert the elements 50, 40, and 30 into the tree
   using Binary Search Tree insertion rules.

3. Update the height of each affected node after
   every insertion.

4. Calculate the balance factor of each node by
   subtracting the height of its right subtree from
   the height of its left subtree.

5. Detect the LL imbalance at node 50 when its
   balance factor becomes +2.

6. Display the tree structure before rotation and
   print the balance factors of the affected nodes.

7. Perform a right rotation at node 50 to restore
   the balance of the AVL tree.

8. Display the tree structure after rotation and
   print the updated balance factors.

9. Display the inorder traversal of the balanced
   tree and print the root node and its balance factor.

10. Verify that node 40 is the root, with node 30
    as its left child and node 50 as its right child.

11. Stop the program.
