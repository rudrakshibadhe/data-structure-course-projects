# Algorithm: AVL Tree LL Rotation

1. Start the program and initialize an empty AVL tree.

2. Insert the elements 30, 20, and 10 into the tree
   using Binary Search Tree insertion rules.

3. Update the height of each affected node after
   every insertion.

4. Calculate the balance factor of each node by
   subtracting the height of its right subtree
   from the height of its left subtree.

5. Detect the Left-Left (LL) imbalance at node 30
   when its balance factor becomes +2.

6. Perform a right rotation at node 30 to restore
   the balance of the tree.

7. Make node 20 the new root, with node 10 as its
   left child and node 30 as its right child.

8. Display the balanced AVL tree and its inorder
   traversal.

9. Verify that the root node has a balance factor
   of 0.

10. Stop the program.
