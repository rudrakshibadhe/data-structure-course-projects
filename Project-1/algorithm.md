# Algorithms

## 1. Add Component

1. Start
2. Create a new component node.
3. Enter component details.
4. Add the node to the component list.
5. Store the component information.
6. Stop.

## 2. Delete Component

1. Start
2. Enter the Component ID.
3. Search for the component.
4. If the component is found, remove the node.
5. Update the links of the list.
6. Display the updated list.
7. Stop.

## 3. Search Component

1. Start
2. Enter the Component ID.
3. Traverse the component list.
4. Compare each component ID with the given ID.
5. If a match is found, display the component details.
6. If no match is found, display "Component not found".
7. Stop.

## 4. Update Component Status

1. Start
2. Enter the Component ID.
3. Search for the component.
4. If found, update its current stage and processing status.
5. Display the updated information.
6. Stop.

## 5. Queue Processing

1. Start
2. Add the component to the rear of the queue.
3. When processing begins, select the component from the front.
4. Process the component.
5. Remove the processed component from the queue.
6. Continue until the queue becomes empty.
7. Stop.

## 6. Stack Processing History

1. Start
2. Record a processing action.
3. Push the action onto the stack.
4. Repeat whenever a new processing action occurs.
5. To view the latest action, access the top of the stack.
6. Pop the action when it is removed from history.
7. Stop.

## 7. Display Components

1. Start
2. Traverse the component list from the first node.
3. Display the details of each component.
4. Move to the next node.
5. Repeat until the end of the list is reached.
6. Stop.

## 8. Overall System Algorithm

1. Start the system.
2. Display the main menu.
3. Select an operation.
4. Perform the selected operation.
5. Update component information and processing records.
6. Display the result.
7. Return to the main menu.
8. Exit when the user selects the exit option.
9. Stop.
